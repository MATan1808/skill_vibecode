# WordPress Dev

Nhánh này chỉ dùng cho dev/fix bug WordPress thông thường.

## Phạm vi

- Theme/child theme/template.
- Plugin, shortcode, widget.
- Gutenberg block.
- CPT/taxonomy/meta field.
- REST API/admin settings/enqueue asset.
- Fix bug PHP/JS/CSS không phải incident security.
