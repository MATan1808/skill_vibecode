# 360-designer UI/UX Rules

1. **Accessibility**: WCAG 2.2 Level AA bắt buộc, contrast ratio tối thiểu 4.5:1.
2. **Touch Targets**: Kích thước tối thiểu 44x44px trên mobile/tablet.
3. **Typography & Spacing Scale**: Tỉ lệ vàng 1.25 (Major Third).
4. **Platform-Safe Adaptation**: Thích ứng an toàn không làm vỡ HTML/XML Odoo, Avada Fusion Builder, Tailwind hay Flutter.
